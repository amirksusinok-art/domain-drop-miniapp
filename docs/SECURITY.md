# Проверка безопасности

## Реализованные меры

- HMAC-SHA256 Telegram initData, timing-safe сравнение, отклонение повторяющихся полей, часовой срок запуска и ограничение будущих timestamps.
- Telegram ID из подписанных данных; username не используется как ключ личности.
- Случайные 256-битные opaque session tokens; в БД только SHA-256, срок 7 дней.
- Bearer auth, same-origin API, без разрешающего CORS, CSP/Helmet, лимит тела 32 KB, rate limits.
- SQL-параметры для входных значений; динамические колонки/сортировка только из серверных whitelist.
- Проверка владельца в каждом действии с доменом, проверка ADMIN_TELEGRAM_IDS на сервере.
- PostgreSQL транзакции и блокировки пользователей/аукционов; неотрицательный баланс и ledger.
- Idempotency key привязан к пользователю, endpoint и payload; повторный запрос возвращает сохранённый ответ.
- Unique pending result и open Scanner на игрока. Карты Scanner не покидают backend до выбора.
- Характеристики домена защищены immutable trigger. Сейф, избранное и Showcase блокируют продажу.
- BOT_TOKEN и WEBHOOK_SECRET только backend. Webhook проверяет секрет, обрабатывает только private chat, дедуплицирует update_id.
- Production отказывается запускать DEV_AUTH и встроенную локальную БД.
- Секреты, initData, SQL параметры и токены не выводятся в application logs.

## Проверки перед массовым запуском

- Пройти реальный Telegram сценарий на iOS и Android после настройки BotFather.
- Настроить резервное копирование и проверить восстановление PostgreSQL.
- Нагрузочный тест на ожидаемую аудиторию и внешняя security review; текущие тесты не являются сертификатом безопасности.
- Для нескольких web instances нужен общий rate-limit store; текущий лимитер рассчитан на один процесс.
- Экономические настройки доступны доверенному администратору: их изменение может изменить RTP. Сначала симулировать баланс.
- Косметические события могут менять распределение стоимости; обычный RTP не заявляется для event spins.

Тестовый стенд не содержит реальных платежей, вывода средств и персональных данных сверх базового профиля Telegram.
